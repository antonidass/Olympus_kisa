## Чек-лист перед запуском Veo (сверять перед каждой генерацией)

Берём из [CONTEXT.md](../../../../CONTEXT.md) → «IP-фильтр Veo» + [GENEALOGY.md](../../../../GENEALOGY.md) → шаг 10 + [CONTEXT.md](../../../../CONTEXT.md) → «Правила промптов для анимации». Проверки разные для двух классов.

1. **Никаких греческих имён в `**Промпт:**`.** Veo блокирует `Cronus / Uranus / Gaia / Rhea / Aphrodite / Hestia / Demeter / Hera / Hades / Poseidon / Zeus / Olympus / Olympian`. Везде вместо них — descriptive из IP-фильтра в шапке файла. Проверить:

   ```bash
   grep -nE 'Cronus|Uranus|Gaia|Rhea|Aphrodite|Hestia|Demeter|Hera|Hades|Poseidon|Zeus|Olympus|Olympian' \
     "content/От Хаоса до Олимпа/часть_02_Власть_Кроноса/prompts/video.md" \
     | grep -v '<!--'
   ```

   Должно быть пусто. Имена допустимы только в комментариях `<!-- ... -->` и заголовках на русском.

2. **Уникальный subject-маркер.** Первые 3–4 слова каждого `**Промпт:**` отличаются от соседних. Проверить:

   ```bash
   grep '^\*\*Промпт:\*\* ' "content/От Хаоса до Олимпа/часть_02_Власть_Кроноса/prompts/video.md" \
     | sed -E 's/^\*\*Промпт:\*\* ([^,]+),.*/\1/' \
     | sort | uniq -c | sort -rn
   ```

   Все строки должны быть с числом `1`.

3. **Обязательный негатив в каждом промпте.** `No speech, no dialogue, no talking, no voices, no mouth movement, no music`. Также избегать слов-триггеров: `shouts, says, speaks, tells, laughs, screams, yells, calls out, sings, cries out`.
