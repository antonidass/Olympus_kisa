# BOGI Promptr — расширение Chrome

Помощник для ручной работы с Google Flow:

- side panel с выбором сценария и списком промптов из `content/<миф>/prompts/{images,stickers,video}.md`
- кнопка **Copy** возле каждой сцены: кладёт промпт в буфер обмена и сдвигает выделение на следующую сцену
- перехват ручного скачивания результата из Flow:
  - если включена галка **«скачать изображения»** и выбран режим `Картинки`,
    скачанный zip/файл импортируется в `content/<миф>/images/`
  - если включена галка **«скачать стикеры»** и выбран режим `Стикеры`,
    скачанный zip/файл импортируется в `content/<миф>/images/stickers/`
    (формат `prompts/stickers.md` совпадает с `images.md` — `## Сцена N` +
    `**Промпт:**`, см. шаг 8 пайплайна в CONTEXT.md)
  - если включена галка **«скачать видео»** и выбран режим `Видео`,
    скачанный zip/файл импортируется в `content/<миф>/video/`
- если включена галка **«авто-разложить по сценам»** (по умолчанию ON),
  сразу после импорта запускается соответствующий distribute-скрипт и
  раскладывает файлы по сценам через subject-маркеры из `prompts/*.md`:
  - `Картинки` → `automation/distribute_images.py` → `images/review_images/scene_NN/vN.jpg`
  - `Стикеры` → `automation/distribute_stickers.py` → `images/stickers/scene_NN_<маркер>.<ext>`
  - `Видео` → `automation/distribute_videos.py` → `video/scene_NN_vM.mp4`
    (сравнивает первый кадр видео с `images/approved_images/scene_NN_vK.<ext>`;
    если approved-картинок ещё нет — distribute ничего не сделает, это
    нормальный сигнал «сначала одобри картинки в webapp»)

## С Flow НЕ взаимодействует

Расширение **не** внедряется на страницу Flow:

- никакого content script на `labs.google` / `aisandbox`,
- никакого перехвата Enter в prompt-инпуте,
- никакого слежения за кнопкой «Download Project» / тостами rate-limit,
- никакого чтения DOM Flow.

Flow считает чтение/имитацию событий своей страницы автоматизацией и может
за это наказывать. Расширение делает в браузере только две безопасные вещи:
пишет в буфер обмена при клике Copy и слушает `chrome.downloads` (это
системное API уровня браузера, не страницы Flow).

## Установка

1. Запустить webapp (он отдаёт расширению список сценариев и промпты):

   ```bat
   webapp\run.bat
   ```

2. Открыть `chrome://extensions`, включить **Developer mode** (правый верхний угол).
3. Нажать **Load unpacked** → выбрать папку `extension/`.
4. Закрепить иконку «BOGI Promptr» на тулбаре. Клик по иконке открывает side panel.

## Использование

1. Открыть [labs.google/fx](https://labs.google/fx/) или нужную страницу Flow.
2. Кликнуть по иконке расширения — справа откроется панель.
3. Выбрать сценарий и тип промптов (Картинки / Стикеры / Видео).
4. На первой сцене нажать **Copy** в side panel → промпт в буфере, выделение сдвинулось на сцену 2.
5. Кликнуть в textarea Flow → Ctrl+V → жми Generate как обычно (мышью или Enter — как тебе удобно).
6. После того как Flow закончил генерацию, возвращаешься в side panel, на следующей карточке жмёшь **Copy**, и так до конца.
7. Когда все сцены прогнаны — три точки в углу Flow → **Download Project**. Браузер скачивает zip, расширение видит это через `chrome.downloads` и (если выбран соответствующий режим и стоит галка) импортирует файл в `content/<миф>/images|stickers|video/` через webapp.

**Кнопка ↩** в шапке — ручной откат на предыдущую сцену (если случайно нажал Copy и хочешь вернуться к незавершённой).

## Известные ограничения

- Перехват скачивания: фильтр по host `labs.google / aisandbox / storage.googleapis.com / flow` и расширениям `.zip/.mp4/.mov/.webm/.m4v/.jpg/.jpeg/.png/.webp`. Если Flow начнёт качать с другого хоста — нужно подкрутить фильтр в [background.js](background.js).
- Sidepanel должен быть открыт в момент скачивания zip, иначе сообщение не дойдёт до UI сразу (background-воркер сохранит pending в `storage.local`, и sidepanel подберёт его при следующем открытии).

## История изменений

- **v0.4.0** — выпилена вся интеграция со страницей Flow (content.js, перехват Enter, rate-limit watcher, клик по «Download Project», прокси буфера обмена через content script). Расширение больше не внедряется на страницу Flow. Копирование промпта теперь — только по клику пользователя в side panel; клик Copy кладёт промпт в буфер и сразу сдвигает выделение на следующую сцену.
- **v0.3.0** — добавлен авто-детект rate-limit Flow и кнопка отката ↩ (удалено в v0.4.0).
- **v0.2.0** — авто-копирование следующего промпта по Enter в prompt-инпуте Flow (удалено в v0.4.0).
- **v0.1.0** — первая версия: список промптов + ручной Copy + перехват скачивания.
