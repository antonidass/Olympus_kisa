# BOGI Flow Promptr — расширение Chrome

Помощник для ручной генерации картинок, стикеров и видео в Google Flow:

- side panel с выбором сценария и списком промптов из `content/<миф>/prompts/{images,stickers,video}.md`
- кнопка **Copy** возле каждого промпта (кладёт в буфер → ты вставляешь Ctrl+V в Flow)
- авто-копирование следующего промпта когда ты жмёшь **Generate** в Flow
- перехват ручного **Download Project** из Flow:
  - если включена галка **«скачать изображения»** и выбран режим `Картинки`,
    скачанный zip/файл импортируется в `content/<миф>/images/`
  - если включена галка **«скачать стикеры»** и выбран режим `Стикеры`,
    скачанный zip/файл импортируется в `content/<миф>/images/stickers/`
    (формат `prompts/stickers.md` совпадает с `images.md` — `## Сцена N` +
    `**Промпт:**`, см. шаг 8 пайплайна в CONTEXT.md)
  - если включена галка **«скачать видео»** и выбран режим `Видео`,
    скачанный zip/файл импортируется в `content/<миф>/video/`

Расширение не имитирует клики и не печатает сам — все действия делает
живой пользователь, поэтому Flow ничего не палит.

## Установка

1. Запустить webapp (он отдаёт расширению список сценариев и промпты):
   ```
   webapp\run.bat
   ```
2. Открыть `chrome://extensions`, включить **Developer mode** (правый верхний угол).
3. Нажать **Load unpacked** → выбрать папку `extension/`.
4. Закрепить иконку «BOGI Flow Promptr» на тулбаре. Клик по иконке открывает side panel.

## Использование

1. Открыть [labs.google/fx](https://labs.google/fx/...) или нужную страницу Flow.
2. Кликнуть по иконке расширения — справа откроется панель.
3. Выбрать сценарий и тип промптов (Картинки / Стикеры / Видео).
4. Первый промпт уже в буфере. Кликнуть в textarea Flow → Ctrl+V → Generate.
5. После клика Generate side panel автоматически переключается на следующую
   сцену и кладёт её промпт в буфер.
6. Когда все сцены прогнаны — три точки в углу Flow → **Download Project**.
   Расширение подхватит скачивание и, в зависимости от выбранного режима и
   галок в панели, импортирует результат в `images/` или `video/` сценария.

## Известные ограничения

- Эвристика на «Generate» (с v0.2.1): ловим клики по элементам, чей текст,
  `aria-label`, `title` или `data-testid` похожи на
  `Generate / Create / Submit / Send / Run / Go / Сгенерировать / Создать /
  Отправить`. Дополнительно ловим **icon-only submit-кнопки** (стрелка ↑/→
  без текста, типичная для Veo Flow): button с SVG внутри + рядом
  textarea/contenteditable в общем контейнере. Также ловим клавиатурный
  сабмит — **Enter** (без Shift) или **Ctrl+Enter** внутри prompt-инпута.
  Если Flow поменяет UI и эти эвристики начнут ложить — подкрутить
  `TRIGGERS` / `looksLikeGenerate` / `isPromptInputArea` в
  [content.js](content.js).
- Перехват скачивания: фильтр на `labs.google / aisandbox / storage.googleapis.com`
  и типы `.zip/.mp4/.mov/.webm/.jpg/.jpeg/.png/.webp`. Если Flow начнёт
  качать с другого хоста или с новым расширением — нужно будет подкрутить
  фильтр в [background.js](background.js).
- Sidepanel должен быть открыт в момент скачивания zip, иначе сообщение
  не дойдёт до UI (background-воркер сохранит pending в `storage.local`,
  и sidepanel подберёт его при следующем открытии).
