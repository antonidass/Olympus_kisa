# TTS EL — расширение Chrome

Помощник для ручной озвучки сценариев в ElevenLabs. Близнец [BOGI Promptr](../extension/README.md), но под TTS.

- side panel со списком предложений сценария из `content/<миф>/voiceover/texts/sentence_NNN.txt`
- кнопка **Copy** возле каждого предложения: кладёт ТЕКСТ в буфер обмена (для вставки в ElevenLabs) и сдвигает выделение на следующее
- перехват ручного скачивания mp3 с **elevenlabs.\***:
  - если включена галка **«скачать аудио»**, скачанный mp3 импортируется в `content/<миф>/voiceover/audio/approved_sentences/<base>_v1.mp3`
  - все старые `approved_sentences/<base>_*.mp3` удаляются (политика «один последний approved на предложение»)
  - привязка скачанного mp3 к конкретному предложению — по **последнему скопированному** (`lastCopiedIdx`). То есть: «нажал Copy на sentence_001 → сгенерил в EL → скачал → mp3 улетел в sentence_001», даже если выделение в панели уехало на sentence_002

## С ElevenLabs НЕ взаимодействует

Расширение **не** внедряется на страницу ElevenLabs:

- никакого content script на `elevenlabs.io` / `*.elevenlabs.io`,
- никакого перехвата клика по Generate / Download,
- никакого чтения DOM EL.

В браузере делает только две безопасные вещи: пишет в буфер обмена при клике Copy и слушает `chrome.downloads` (системное API уровня браузера, не страницы EL).

## Установка

1. Запустить webapp (он отдаёт расширению список сценариев и тексты):

   ```bat
   webapp\run.bat
   ```

2. Открыть `chrome://extensions`, включить **Developer mode** (правый верхний угол).
3. Нажать **Load unpacked** → выбрать папку `extension_tts_el/`.
4. Закрепить иконку «TTS EL» на тулбаре. Клик по иконке открывает side panel.

> Можно держать BOGI Promptr и TTS EL установленными одновременно — это разные расширения, они не пересекаются (BOGI Promptr слушает `labs.google/aisandbox`, TTS EL — `elevenlabs.*`).

## Использование

1. Открыть [elevenlabs.io](https://elevenlabs.io/app/) и нужный voice.
2. Кликнуть по иконке расширения — справа откроется панель.
3. Выбрать сценарий.
4. На первом предложении нажать **Copy** в side panel → текст в буфере, выделение сдвинулось на предложение 2.
5. Кликнуть в textarea EL → Ctrl+V → Generate.
6. Когда озвучка готова — нажать в EL **Download** (mp3). Расширение видит скачивание через `chrome.downloads`, импортирует mp3 в `approved_sentences/sentence_NNN_v1.mp3` и подсвечивает карточку как `★ v1`.
7. Возвращаешься в side panel, на следующей карточке жмёшь **Copy**, и так до конца.

**Кнопка ↩** в шапке — ручной откат на предыдущее предложение (если случайно нажал Copy и хочешь вернуться к незавершённому).

## Известные ограничения

- Фильтр скачиваний: `elevenlabs` в URL + `.mp3` в имени файла. Если EL поменяет CDN — нужно подкрутить `looksLikeElDownload` в [background.js](background.js).
- Привязка mp3 → предложение идёт по `lastCopiedIdx`. Если успеешь скачать ДВА mp3 подряд без промежуточного Copy — оба улетят в одно и то же предложение, второй перезапишет первый. Поведение совпадает с workflow «один Copy → один Download».
- Sidepanel должен быть открыт в момент скачивания mp3, иначе сообщение не дойдёт до UI сразу (background-воркер сохранит pending в `storage.local`, и sidepanel подберёт его при следующем открытии в течение 2 минут).
